# Atalhos de teclado

❖ é a tecla Super, ⌃ Ctrl, ⌥ Alt e ⇧ Shift. [Ajustes → Teclado](settings:keyboard) lista os atalhos em
uso e escolhe entre os do **macOS** (o padrão) e os do **Linux / Windows**.

## Sempre

| Atalho | O que faz |
|---|---|
| ❖Espaço · ⌃Espaço | Buscar: apps, arquivos, ajustes e ajuda |
| ❖⌥Espaço · ⌃⌥Espaço | Próximo teclado ou método de entrada |
| ❖V · ❖⇧V | Área de transferência: últimos itens · histórico completo |
| ❖. | Emoji e símbolos |
| ❖⇧3 · Print Screen | Captura da tela inteira |
| ❖⇧4 | Captura de uma área (Espaço: de uma janela) |
| ❖⇧5 | Painel de capturas e gravação de tela |
| ❖L · ❖⌃Q | Bloquear a tela |
| ❖Q | Sair do app |
| Teclas de mídia | Tocar, pausar, próxima e anterior no Player |

## Alternar entre apps

Segure o modificador e toque em Tab: uma faixa de ícones mostra o nome do app escolhido, com os mais
recentes primeiro. Tab avança, ⇧Tab volta, Esc cancela e soltar o modificador alterna. Um toque rápido
volta ao app anterior.

## Atalhos macOS (o padrão)

| Atalho | O que faz |
|---|---|
| ❖ sozinho · F4 | Apps (o lançador de apps) |
| ❖Tab · ❖⇧Tab | Alternar entre apps |
| ⌃↑ · ⌃↓ | Visão geral · janelas do app ([Áreas de trabalho](help:desktops)) |
| ⌃← ⌃→ | Anterior ou seguinte |
| ❖\` · ❖⇧\` | Janela seguinte ou anterior do app |
| ❖M | Minimizar a janela |
| ❖H · ❖⌥H | Ocultar o app · ocultar os outros apps |
| ❖⌥Esc | Forçar encerramento |
| ❖F11 | Mostrar a área de trabalho, e voltar |
| ❖⌥D | Ocultar ou mostrar o Dock automaticamente |
| ❖, | Ajustes do app |

Em um app Linux, ❖C, V, X, A, Z, F, T, W, N, L, R, P e S chegam como Ctrl (como Ctrl+Shift em um
emulador de terminal, onde Ctrl+C é a interrupção), só para esse app. Por isso ❖V cola e ❖L é o Ctrl+L
dele: com um app Linux à frente a tela bloqueia com ❖⌃Q e a área de transferência abre com ❖⇧V. Em um
app do Axia DE dentro da sessão ❖V também cola; ❖⇧V é a área de transferência.

## Atalhos Linux / Windows

Com **Linux / Windows** escolhido em [Ajustes → Teclado](settings:keyboard), estes ficam no lugar dos
do macOS:

| Atalho | O que faz |
|---|---|
| ⌥Tab · ⌥⇧Tab | Alternar entre apps (❖Tab também) |
| ⌥\` · ⌥⇧\` | Próxima ou anterior janela do app |
| ❖⌃← ❖⌃→ | Área de trabalho anterior ou seguinte |
| ❖⌃D · ❖⌃F4 | Nova área de trabalho · fechar esta |
| ❖←→↑↓ | Encaixar a janela |
| ❖H | Minimizar a janela |
| ⌥F4 | Fechar a janela |
| ❖D | Mostrar a área de trabalho, e voltar |
| ❖E · ❖I | Arquivos · Ajustes |
| ❖⇧S | Captura de uma área |
| ❖L | Bloquear a tela |
| ⌃⇧Esc | Monitor |

## Nos apps

⌃Tab e ⌃Q sozinho ficam sempre com o app: no Terminal, ⌃Q é do terminal.

| Atalho | O que faz |
|---|---|
| ❖N · ❖T · ❖W | Nova janela · nova aba · fechar |
| ❖F · ❖G | Buscar · próximo resultado |
| ❖C · ❖X | Copiar · cortar |
| ❖Z · ❖⇧Z | Desfazer · refazer |
| ❖S · ❖P | Salvar · imprimir |

Cada app explica os seus no artigo dele: [Arquivos](help:files), [Terminal](help:terminal),
[Editor de texto](help:editor) e [Notas](help:notes).
